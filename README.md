# 🌸 Rutube Playlist Parser

> Стильный и минималистичный веб-сервис для парсинга всех ссылок на видео из плейлистов Rutube, выполненный в нежных пастельных тонах.

---

## ✨ Возможности

- **100% обход страниц:** Rutube ограничивает выдачу 20 видео на страницу. Парсер автоматически опрашивает все страницы плейлиста последовательно без ограничений, извлекая каждую ссылку.
- **Поддержка любых форматов ссылок Rutube:**
  - `https://rutube.ru/plst/308547/`
  - `https://rutube.ru/playlist/308547`
  - `rutube.ru/plst/308547`
  - Прямой ID: `308547`
  - Ссылки на видео с меткой плейлиста: `rutube.ru/video/xxxx/?plst=308547`
  - Каналы Rutube: `rutube.ru/channel/639184/` и `rutube.ru/u/rutube/`
- **Живой поток прогресса (SSE):** Прогресс отображается в реальном времени с индикатором страниц и количества найденных видео.
- **Копирование в 1 клик:**
  - Быстрое копирование всех прямых ссылок на видео в буфер обмена.
  - Гибкие форматы: чистые URL, нумерованный список `#1 URL`, `Заголовок — URL`, Markdown `[Заголовок](URL)`.
  - Возможность копировать отдельные ссылки или выборочно чекбоксами.
- **Экспорт данных:**
  - **.TXT** — чистый список прямых ссылок (по 1 на строку), готовый для jDownloader или yt-dlp.
  - **.CSV** — таблица со всеми метаданными (№, Название, Ссылка, Хронометраж, Автор, Просмотры, ID) с поддержкой UTF-8 BOM для корректного открытия в Excel.
  - **.JSON** — полная структурированная схема данных для разработчиков.
  - **.MD** — оформленный Markdown-документ.
- **Три режима просмотра:**
  - **Карточки:** красивые карточки с превью, бейджем хронометража, автором, заголовком и кнопками.
  - **Список:** компактная таблица с поиском и сортировкой.
  - **Текст:** текстовое поле с прямым доступом ко всем ссылкам.
- **Интерактивный поиск и сортировка:** мгновенная фильтрация по названию или автору, сортировка по хронометражу и алфавиту.
- **Дизайн в нежных тонах:** чистый, воздушный минимализм, мягкие градиенты (лаванда, чайная роза, шалфей, персик), эффект матового стекла (glassmorphism) и плавная анимация.

## 🚀 Быстрый запуск

### Вариант 1 (Windows — двойной клик)
Запустите файл:
```
start.bat
```

### Вариант 2 (Командная строка)
```bash
python run.py
```
Сервер автоматически подберет свободный порт (по умолчанию `http://127.0.0.1:8000`) и откроет страницу в браузере.

---

## 🛠 Технологический стек

- **Backend:** Python 3, FastAPI, Uvicorn, Server-Sent Events (SSE), urllib/json (без лишних внешних зависимостей).
- **Frontend:** Ванильный HTML5, CSS3 (кастомные CSS-переменные, стекломорфизм, микроанимации), современный модульный JavaScript (Fetch API, EventSource, Clipboard API).

---

## 📡 API Эндпоинты

- `GET /api/stream?url=...` — Потоковый SSE-эндпоинт с живым отображением прогресса загрузки страниц.
- `POST /api/parse` — Стандартный REST-запрос, возвращающий JSON с метаданными и массивом ссылок.
- `GET /api/info?url=...` — Быстрое получение только заголовка и количества видео в плейлисте.
- `GET /api/samples` — Предустановленные примеры плейлистов для быстрого тестирования.
